# 🎖️ SHARP Decision Game

An interactive decision-making simulator designed to reinforce leadership, ethical decision making, and SHARP awareness through realistic scenarios.

## Overview

The SHARP Decision Game presents players with workplace situations that require critical thinking and leadership. Players make decisions throughout the scenario and experience different outcomes based on their choices.

The goal is to encourage discussion, improve decision-making skills, and reinforce Army leadership principles.

## Features

- Interactive scenario gameplay
- Branching decision paths
- Multiple possible outcomes
- Leadership-focused scenarios
- Immediate feedback
